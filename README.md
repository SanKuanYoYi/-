# -
一个“顺路捎”校园快递代取撮合板，让群里的顺路运力被看见，让代取从刷屏询问变成可匹配、可追踪的顺手互助。


谁会用：
经常在校园跳蚤群、班级群里找人代取快递的同学；愿意顺路帮带快递的同学；以及需要减少群内重复刷屏的群管理员。

如何体验：
打开作品链接后，在首页按驿站、时间、物件大小筛选；代取者可发布“顺路班次”，需求者可发布“标准代取单”；系统按驿站、时间窗、送达区域和剩余容量推荐匹配。接单后取件码才脱敏可见，随后按“已接单→已取件→送达中→已完成”推进状态，完成后可上传凭证并生成分享卡片发回群里。

可以得到什么结果：
需求者能更快找到顺路代取，价格有参考，状态不用反复问；代取者能提前发布顺路班次，减少重复沟通；群聊里的代取信息从刷屏变成一张状态清晰的卡片。作品只做信息撮合，不碰支付，取件码和手机号默认保护，让顺路帮忙更省事、更透明、更安心。
